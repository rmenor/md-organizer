Historial y Control de Versiones

Gestión inteligente de versiones: los libros entrantes con fecha superior sustituyen la versión anterior; las versiones inferiores son advertidas para evitar pérdidas.

Guía: Cómo Crear y Comprimir Libros Markdown

Instrucciones, especificación de paquetes y herramientas para preparar tus publicaciones

1

Estructura de Carpetas Recomendada

Organiza tus capítulos Markdown de forma secuencial y crea una carpeta assets/ para imágenes:

mi-libro/
├── metadata.json                 (Opcional pero recomendado)
├── 01_introduccion.md
├── 02_fundamentos.md
└── assets/
    └── cover.png
2

Control de Versiones y Código

Cada libro debe incluir en su metadata.json o encabezado YAML los campos:

  • code: Identificador único del libro (ej: BK-CLEAN-CODE).
  • version: Versión semántica (ej: 1.0.0).
  • date: Fecha de publicación (ej: 2024-01-15).
Regla de sustitución automática: Si subes un libro con el mismo code y fecha posterior, se sustituirá automáticamente. Si la fecha es anterior o igual, la aplicación avisará que ya está instalada una versión superior.
3

Compresión en ZIP

Comprime el contenido de la carpeta (no la carpeta contenedora externa), de modo que metadata.json o el primer fichero Markdown quede en la raíz del ZIP.

Plantilla oficial recomendada: 
{
  "code": "BK-GUIA-PRACTICA",
  "version": "1.0.0",
  "date": "2024-01-15",
  "title": "Título de la Publicación",
  "author": "Nombre del Autor",
  "description": "Breve sinopsis de la obra.",
  "section": "Ingeniería de Software",
  "subsection": "Buenas Prácticas",
  "language": "es",
  "cover": "assets/cover.png",
  "chapters": [
    { "title": "Capítulo 1: Introducción", "file": "01_introduccion.md" },
    { "title": "Capítulo 2: Conceptos Clave", "file": "02_conceptos.md" }
  ]
}

Ejecución Local en 60 Segundos

Puedes ejecutar tu propia instancia local en tu ordenador o servidor con Node.js:

git clone https://github.com/rmenor/md-organizer.git
cd md-organizer
npm install
npm start

Abre http://localhost:3000 en tu navegador web.

✨

Características de la Versión v1.0.0

  • Ingesta de Libros ZIP: Extracción segura e indexación de capítulos Markdown en SQLite.
  • Motor de Control de Versiones: Detección automática de códigos de libro y sustitución de versiones más recientes.
  • Lector Tipográfico Multitema: Modos Oscuro, Sepia y Claro, paginación fluida, ajuste de fuentes y visor TOC.
  • Cuadrícula Dinámica de Secciones: Generación automática de baldosas según las categorías de los libros.
  • Despliegue Serverless en Vercel: Configuración optimizada con redirección a /tmp para entornos efímeros.
