# 2. Perfil de Libros y Capítulos

El **Book Profile** define una estructura canónica para libros técnicos, manuales y colecciones de lectura:

```text
Book Package (.mdz)
├── manifest.json
├── metadata/
│   └── book.json
├── chapters/
│   ├── 01_intro.md
│   └── 02_setup.md
└── assets/
    └── cover.png
```
